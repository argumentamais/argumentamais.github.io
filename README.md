# argumentamais.github.io

Site da Argumenta MAIS no GitHub Pages.

- `/bio/`: página de link na bio do Instagram
- `/black/`: cadastro da lista de espera da Black 2027 (envia para a planilha do Google Sheets via Apps Script)
- `/black-oferta/`: página de captura chamativa da Black 2027 (contagem regressiva e pop-up de saída; envia para a mesma planilha do `/black/`)
- `/super2026/`: cadastro para os superintensivos de reta final (nome, curso e vestibulares de 2026; envia para uma planilha própria via Apps Script)
